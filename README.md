# Trital

*The school of Jupiter.* A Rivals-style 4v4 arena game on a small spherical planet.
You always stand on top. Big caricature heads, flame hair after a triple kill, a gym
basketball opening, and a queue ladder to challenge the League Champs.

## Play loop

1. Spawn in the **school gymnasium** (curved to hug the planet surface). Play pickup basketball.
2. Team up into squads of **4** and join the **queue** when challenged.
3. Squads line up and face the **League Champs** — winner stays, loser rejoins the end of the line.

## Build

Copy each file into Roblox Studio according to its header (`Script`, `LocalScript`,
`ModuleScript`) and the path under `src/`. See `PLAN.md` for the roadmap.

## Workflow

Branch → PR → squash-merge into `main`; one GitHub issue per workstream.
